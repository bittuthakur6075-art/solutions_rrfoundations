## 2. Product Schema & Metadata

Each verified item carries:
- `id`: Unique Store Identifier
- `title`: Product Commercial Title
- `slug`: Canonical URL slug
- `category`: Category slug reference
- `description`: Detailed technical description
- `materials`: Material composition (e.g. Pure Copper, Stainless Steel 304, High-Density MDF, Satin Woven Polyester)
- `specifications`: Dimensions, finish type, fastening mechanism, minimum production batch
- `thumbnail` & `images`: High-res studio assets
- `featured`: Homepage showcase flag
- `seo`: Pre-generated search title & description
